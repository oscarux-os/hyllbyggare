# Anamosa hyllbyggare – Färdiga moduler (presets)

Levande dokument. Listar färdiga konfigurationer (presets) per **Mio-kategori** som Anamosa passar för, och vilka variationer man kan göra på var och en.

Variationerna bygger på valen i [[Konfigurationsval]]. Redigeringsaxel per kategori finns i [[Interaktionsmodell]]. Tanken: kunden börjar från en färdig modul och justerar inom dess ramar (eller bygger fritt från start).

Endast relevanta Mio-kategorier är med (urval och motivering: se [[Interaktionsmodell]]).

---

## Byråar
Låg/mellanhög lådmöbel, sektioner av lådor i bredd. Redigeringsaxel: **kolumn**.
Renderingar: indikativt s.7–9 (lådsektioner).

**Variationer:**
- Frontstil: Plain / Slats (ej Glass på lådfronter)
- Innehåll per ruta: mest lådor, valfritt öppet/lucka
- Handtag: variant 1 / 2 / 3 / push-open
- Montering: stående (ben) eller väggmonterad
- Ben: rund träfot / sockel / mässingsben / svart stålben
- Finish/färg: hela paletten
- Bredd/höjd: stegad

## Hyllor
Hög och/eller bred, mest öppna kuber i rutnät (bokhylla / vägghylla). Redigeringsaxel: **rad**.
Renderingar: s.10–19.

**Variationer:**
- Frontstil (vid stängda fack): Plain / Slats / Glass, gärna mix per rad
- Innehåll per ruta: mest öppet, valfria stängda fack och hyllplan
- Hyllplan: dela öppna fack i 3 lägen
- Montering: väggmonterad (svävande) eller stående
- Finish/färg: hela paletten, inkl. tvåton (mörk stomme + färgad/trä front, s.16, 19)
- Bredd/höjd: stegad (t.ex. 4×4-rutnät)

## Skåp & vitrinskåp
Högt skåp med glasluckor upptill, stängt nedtill (highboard). Redigeringsaxel: **rad**.
Renderingar: s.23, 24.

**Variationer:**
- Frontstil: Glass upptill, Plain/Slats nedtill
- Innehåll per ruta: glaslucka (display) + lucka/låda (förvaring) + hyllplan
- Montering: stående (ben/sockel)
- Ben: rund träfot / sockel / mässingsben / svart stålben
- Finish/färg: hela paletten
- Höjd: stegad

## Skänkar
Låg, bred enhet med mix av luckor, lådor och öppna fack. Redigeringsaxel: **kolumn**.
Renderingar: s.7, 8, 9.

**Variationer:**
- Frontstil: Plain / Slats / Glass
- Innehåll per ruta: lucka / låda / öppen + hyllplan
- Montering: stående (ben) – kan ev. även väggmonteras
- Ben: rund träfot / sockel / mässingsben / svart stålben
- Finish/färg: hela paletten
- Bredd: stegad

## TV-bänkar
Låg avlång enhet, eller hel mediavägg där TV omges av förvaring. Redigeringsaxel: **kolumn**.
Renderingar: s.6, 20, 21, 22.

**Variationer:**
- Format: enkel låg bänk → bänk + sidoskåp + vägghylla (mediavägg)
- Frontstil: Plain / Slats / Glass
- Innehåll per ruta: öppet (för utrustning) / lucka / låda
- Montering: stående (ben) eller svävande
- Ben: rund träfot / sockel / mässingsben / svart stålben / vinklade träben (s.21)
- Finish/färg: hela paletten
- Bredd/höjd: stegad

## Hallmöbler (delvis)
Hallförvaring / smalt skåp. Redigeringsaxel: **beror** (rad om hög, kolumn om låg).
Renderingar: ingen explicit – härledd användning.

**Variationer:**
- Frontstil: Plain / Slats / Glass
- Innehåll per ruta: lucka / låda / öppet + hyllplan
- Montering: stående eller väggmonterad
- Ben: rund träfot / sockel / mässingsben / svart stålben
- Finish/färg: hela paletten
- Bredd/höjd: stegad

> Obs: krok-/hängare-delen i Mios hallmöbler ingår inte i Anamosa.
